# ربات تلگرام استعلام قطعی برق گلستان (Power Bot) ⚡️💡
> Telegram Bot for Golestan Province Electricity Outage & Blackout Schedules (GOPED)

این پروژه یک ربات کامل و پیشرفته تلگرام است که زمان‌بندی خاموشی‌های برق استان گلستان را مستقیماً از سامانه جدید شرکت توزیع نیروی برق گلستان (`modiriattolid.goped.ir`) دریافت کرده و به کاربران نمایش می‌دهد.

---

## ✨ ویژگی‌ها (Features)

- ⚡️ **استعلام سریع:** ارسال شناسه قبض ۱۳ رقمی و دریافت لحظه‌ای وضعیت خاموشی.
- 📅 **فیلترهای زمانی:** مشاهده برنامه **امروز**، **فردا** و **کل هفته** با دکمه‌های شیشه‌ای تعاملی.
- 🔖 **سیستم نشان‌شده‌ها (Bookmarks):** نشان کردن شناسه‌های مختلف با نام دلخواه و دسترسی ۱-کلیکه مستقیم از روی کیبورد.
- ⏰ **هشدار خودکار روزانه:** ارسال پیام یادآوری در صورت وجود قطعی برق در روز جاری (ساعت ۸:۰۰ صبح).
- 📢 **ارسال پیام همگانی (`/shout`):** ارسال پیام، عکس یا فوروارد به تمامی کاربران ربات همراه با گزارش ارسال.
- 👥 **مشاهده آمار و لیست کاربران (`/users`):** مشاهده تعداد کاربران، نشان‌ها و مشخصات کاربران استارت‌زده.
- 🔢 **پشتیبانی کامل از ارقام فارسی:** تبدیل خودکار اعداد فارسی (`۱۲۳۴...`) به انگلیسی.
- 📢 **اطلاعیه‌های رسمی:** دریافت آخرین پیام‌ها و اطلاعیه‌های شرکت توزیع برق.
- ☁️ **پشتیبانی از دو روش اجرا:**
  - اجرای مستقیم با **Node.js / Docker** (روی سیستم یا سرور مجازی / VPS).
  - اجرای ۱۰۰٪ رایگان روی **Cloudflare Workers** (بدون نیاز به سرور).

## 🛠 جزئیات فنی و مهندسی معکوس API

وب‌سایت جدید شرکت توزیع برق بر پایه **Blazor WebAssembly** پیاده‌سازی شده است. از طریق بررسی و دیکامپایل اسمبلی‌های کلاینت:
- **آدرس اصلی API:** `https://modiriattolid.goped.ir:8090/`
- **هدر احراز هویت:** `Auth-Token: 7f3c2a91-6d84-4b17-a5e9-2c0f8d6b31a4`
- **اندپوینت استعلام زمان‌بندی:** `GET /Api/GetSchedule_Web?BillId={شناسه_قبض}`
- **اندپوینت اطلاعیه‌ها:** `GET /Api/GetNotice`
- **کپچا (CAPTCHA):** کپچای موجود در وب‌سایت صرفاً یک اعتبارسنجی سمت کلاینت (MudBlazor) بوده و اندپوینت API سرور نیازی به حل کپچا ندارد.

## 🚀 راهنمای راه‌اندازی (Setup Guide)

### ۱. دریافت توکن ربات تلگرام
1. در تلگرام وارد ربات [@BotFather](https://t.me/BotFather) شوید.
2. دستور `/newbot` را ارسال کرده و نام و یوزرنیم ربات خود را انتخاب کنید.
3. توکن داده شده (مثلاً `123456789:ABCdefGHIjkl...`) را کپی کنید.

### ۲. تنظیم متغیرهای محیطی
فایل `.env` را در ریشه پروژه باز کرده و توکن خود را در آن قرار دهید:
```env
BOT_TOKEN=توکن_ربات_شما
```

## 💻 روش‌های اجرا

### روش اول: اجرای مستقیم با Node.js
```bash
# نصب وابستگی‌ها
npm install

# اجرای تست‌ها برای اطمینان از سلامت اتصال به API
npm test

# اجرای ربات
npm start

# حالت توسعه (با راه‌اندازی مجدد خودکار)
npm run dev
```

### روش دوم: اجرا با Docker و Docker Compose
```bash
docker compose up -d --build
```

### روش سوم: اجرا روی Cloudflare Workers (بدون سرور)
اگر تمایل دارید ربات را روی کلادفلر ورکرز مستقر کنید:
```bash
cd cf-worker
npm install wrangler -g

# لاگین در اکانت کلادفلر
wrangler login

# تنظیم توکن ربات به عنوان سکرت
wrangler secret put BOT_TOKEN

# انتشار ورکر
wrangler deploy
```
سپس وب‌هوک تلگرام را با آدرس ورکر خود ست کنید:
```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://<YOUR_WORKER_SUBDOMAIN>.workers.dev
```
